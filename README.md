# LvPlanning — نظام تخطيط إنتاج المكملات | Le Voile

نظام Laravel 12 بواجهة عربية RTL بيغطي الدورة كاملة زي ما بتحصل على الورق.

**مفيش اعتمادات.** اللي بيعمل المستند هو اللي بيقرره: أول ما يحفظ، أثره بينزل
على المخزون فورًا والخطوة اللي بعده بتظهر عند صاحبها في نفس اللحظة.

| عايز تفهم | افتح |
|---|---|
| السيستم كله في 5 دقايق (جولة متحركة) | [`public/tour.html`](public/tour.html) — على السيرفر: `/tour.html` |
| الفلو خطوة خطوة وإزاي تجرّبه | [`دليل-الفلو-الجديد.md`](دليل-الفلو-الجديد.md) |
| كل معادلة وكل رقم في الشاشات جاي منين | [`دليل-المعادلات.md`](دليل-المعادلات.md) |
| الرفع على السيرفر وحل الإيرورات | [`DEPLOY.md`](DEPLOY.md) |

المنيو مرتّب بنفس ترتيب الدورة، والخطوات مترقّمة **1 ← 13**:

### ① دورة الشراء — مستند واحد على تلات أيادي
```
[1] التخطيط          ⇒ [2] المشتريات         ⇒ [3] الحسابات
    اللون + الصنف          المورد + السعر          علم بالمستحق (متابعة مش بوابة)
    الكمية + الوحدة        تاريخ التوريد
    نسبة الزيادة           طريقة الدفع      ⇒ الطلب جاهز للاستلام في المخزن
```

### ② وصول القماش — الترتيب ده مقصود
```
[4] إذن إضافة  ⇒ بيولّد الرسالة (الحوض) ويدخّلها المخزن محجوزة «تحت الفحص»
       ↓            القماش مش متاح للتشغيل من هنا
       ↓            (استلام مباشر/حاويات ⇒ بتدخل مُفرَج عنها على طول)
[5] تقرير فحص  ⇒ جرد الأتواب (المعدود مقابل المصرّح) + عرض كل توب ⇒ أقل عرض
       ↓
[6] تقرير معمل ⇒ وزن البنشر + الانكماش + مطابقة اللون
       ↓
[7] إذن استلام خام ⇒ الإفراج — السليم يبقى متاح لأوامر الشغل، والمرفوض للمرتجعات
```

### ③ التشغيل
```
[8] طلب ماركر → [9] ماركر → [10] أمر شغل (الحسبة) → [11] صرف خام → [12] بيان قص → [13] استلامات → قفل تلقائي
```

بالإضافة للفوركاست وأيام التغطية ونسب الألوان.

## التشغيل لأول مرة

من داخل `C:\xampp\htdocs\LvPlanning` في CMD أو PowerShell:

```bash
composer install
php artisan key:generate
```

اعمل قاعدة بيانات فاضية اسمها `lvplanning` من phpMyAdmin (Collation: `utf8mb4_unicode_ci`)،
وراجع بيانات الاتصال في ملف `.env` (المستخدم `root` والباسورد فاضي = الإعداد الافتراضي لـ XAMPP).

```bash
php artisan migrate --seed
php artisan storage:link
php artisan lv:doctor      # فحص شامل — لازم كله أخضر
```

افتح: **http://localhost/LvPlanning/public**

## الرفع على السيرفر

`.envlive` فيه بيانات `planning.levoilestores.com` جاهزة. على السيرفر:

```bash
cp .envlive .env
composer install --no-dev --optimize-autoloader
php artisan key:generate
php artisan migrate --force
php artisan storage:link
php artisan config:cache && php artisan route:cache && php artisan view:cache
```

- الـ Document Root لازم يشاور على مجلد **`public`**
- صلاحيات الكتابة على `storage/` و `bootstrap/cache/`
- `--seed` **متشغلوش على اللايف** — الداتا الديمو للتجربة المحلية بس
- `.env` و `.envlive` مستثنيين من Git

## امشِ الفلو بنفسك

**الرقم الأحمر جنب أي شاشة في المنيو معناه: فيه شغل عليك هناك دلوقتي.**
كل دور بيشوف أرقامه هو، والرقم لازم يوصل صفر لما تخلّص.

الأرقام هنا هي نفس أرقام الخطوات في المنيو.

### ① الشراء
1. `planner` → **1 · طلبات الشراء** → طلب جديد: لون + صنف + كمية + وحدة + نسبة زيادة. **الحفظ بينزّله للمشتريات.**
2. `moaz` → **2 · التسعير** (هتلاقي رقم أحمر) → المورد + الأسعار + تاريخ التوريد → حفظ = الطلب جاهز للاستلام.
3. `finance` → **3 · المستحقات** → «سجّل علمك» — متابعة بس، مش بتوقف حاجة.

### ② وصول القماش
4. `store` → **4 · إذن إضافة**: اختار الطلب + اللي استلمته + **عدد الأتواب** → حفظ.
   → كل (خامة + لون) بتبقى رسالة لوحدها بحالة «تحت الفحص» والكمية محجوزة.
5. `qc` → **5 · فحص القماش** → اجرد الأتواب وسجّل عرض وطول كل توب
   → السيستم بيطلّع **أقل عرض** ويحذّرك لو فيه فرق في الجرد.
6. `lab` → **6 · تقرير المعمل** → قراءات البنشر والانكماش.
7. `store` → **7 · إذن استلام خام** → راجع واحفظ = **الإفراج**. لو فيه أتواب مرفوضة، اكتبها في نفس الفورم.
   جرّب تعمل الإذن ده قبل الفحص — السيستم هيمنعك.

### ③ التشغيل
8. `planner` → **8 · طلبات الماركر** على أقل عرض.
9. `pattern` → **9 · الماركرات** → طول الفرشة وقطعها.
10. `planner` → **10 · أوامر الشغل** → الرسالة + الماركر + المصنع + الكمية — الحسبة بتتحدث لحظيًا قبل الحفظ.
11. `store` → **11 · إذن صرف خام** — الجزئي مسموح.
12. `follow` → **12 · بيان قص**: غيّر طول الفرشة الفعلي وشوف الانحراف.
13. `store` → **13 · استلامات الإنتاج** على دفعات لحد ما الأمر يتقفل لوحده.

عايز تجرّب الأرقام من غير مستندات؟ **حاسبة التخطيط**.

## محرك الحسابات

```
عدد الرِقّات   = FLOOR(طول التوب ÷ طول الفرشة)
وزن الرِقّة    = طول الفرشة × (أقل عرض ÷ 100) × متوسط البنشر ÷ 1000
استهلاك القطعة = وزن الرِقّة ÷ عدد القطع في الفرشة
القطع المتوقعة = الكيلوهات المخصصة ÷ استهلاك القطعة
```

**أقل عرض مش المتوسط** — لأن الماركر لو طلع أوسع من القماش هنحرق الجنب ونرميه.
**كل رقم من هنا متوقّع** لأنه مبني على عيّنة فحص. الفرق الطبيعي مع الفعلي **2-4%**.

## القواعد المزروعة في السيستم

| القاعدة | فين اتطبقت |
|---|---|
| ممنوع خلط حوضين في قطعة واحدة | أمر الشغل = حوض واحد فقط |
| الماركر ما ينفعش يتعدى عرض القماش | تحذير أحمر بيمنع إرسال أمر الشغل |
| الفحص عيّنة مش 100% | نسبة العيّنة محفوظة وبتظهر على كل حسبة |
| فرق العرض الكبير بين أتواب حوض واحد = القماش بايظ | تنبيه تلقائي فوق 5 سم |
| الزيادة في طول الفرشة بتاكل رِقّات | شاشة "تأثير فرق طول الفرشة" |
| الانحراف فوق 4% لازم سبب مكتوب | بيان القص مش بيتبعت من غيره |
| نسبة الزيادة المسموح بها في التوريد (5%) | إذن الاستلام بيرفض التجاوز |
| ممنوع تشغيل قماش ما اتفحصش | الكمية محجوزة من إذن الإضافة لحد الإفراج بإذن الاستلام |
| ممنوع إفراج من غير فحص ومعمل معتمدين | إذن الاستلام بيرفض الإرسال |
| فرق جرد الأتواب عن المصرّح | تنبيه فوري لمراقب المخزون |
| كل مرحلة بتقفل اللي قبلها | التخطيط ما يعدّلش أصناف بعد ما تنزل للمشتريات |
| مبيعات QuickBooks بتتعدّل طول الشهر | الشهر ما يتقفلش غير يوم 5 من الشهر التالي |
| دستة تتسجّل قطعة | تحويل تلقائي + علامة على الأرقام الشاذة |
| أكواد الألوان ممنوع تتحذف | دمج وإيقاف بس — الكود القديم بيفضل ويشاور على الجديد |

الأرقام دي كلها في `config/lvplanning.php` — تقدر تغيّرها من غير كود.

## الصلاحيات

كل راوت متقفل بصلاحية. الأدوار وصلاحياتها متزرعة جاهزة، وتقدر تعدّلها من
**الإعدادات ← الأدوار والصلاحيات**. القايمة الجانبية بتخفي أي شاشة المستخدم
مالوش صلاحية عليها — فكل دور بيشوف شغله بس. `admin` بيعدّي على كل حاجة.

جرّب: ادخل بـ `lab` وشوف إن القايمة فيها الجودة والبيانات الأساسية بس.

## من غير اعتمادات

دورة الاعتماد اتشالت بالكامل (الكود والشاشات والجداول). المستند يا **مسودة** يا **تم**:
«تم» معناها إن آثاره اتنفذت (رصيد الرسالة، حركة المخزون، طلب الشراء...) والخطوة اللي
بعدها نزلت لصاحبها. كل ده بيتسجّل في **سجل الحركة** باسم اللي عمله.

لو بترقّي نسخة قديمة كان فيها مستندات «تحت الاعتماد»، شغّل `php artisan lv:finish-pending`
بعد `migrate` — بيقفلها واحد واحد بنفس المسار الطبيعي فأثرها يتطبّق صح.

## الاستيراد والتصدير

من شاشة **استيراد وتصدير**، وفيها قوالب إكسيل جاهزة:

| الملف | الأعمدة |
|---|---|
| الألوان | `code, name, family, hex, is_basic, legacy_code, merged_into` |
| المبيعات | `model_code, qty, unit` |
| الأرصدة | `model_code, color_code, warehouse_code, qty` |

عمود `merged_into` في ملف الألوان بيعمل الدمج تلقائيًا — ده الطريق العملي
لتنظيف آلاف أكواد الألوان دفعة واحدة من غير ما تخسر الداتا التاريخية.

## الأوامر

| الأمر | بيعمل إيه |
|---|---|
| `php artisan lv:doctor` | فحص شامل: البيئة، الداتابيز، الأعمدة الناقصة، الصلاحيات، إعدادات الجلسة. كل سطر أحمر معاه الحل. |
| `php artisan lv:demo` | **ديمو كامل** — السيستم وهو شغّال: طلبات في كل مرحلة، أحواض في كل حالة، أوامر شغل، 18 شهر مبيعات |
| `php artisan lv:master` | **بيانات أساسية بس** — موردين ومصانع وخامات وألوان وموديلات، **من غير أي مستندات**. دي نقطة البداية للشغل الحقيقي |
| `php artisan lv:reset` | يمسح كل بيانات الشغل ويسيب المستخدمين والأدوار |
| `php artisan lv:finish-pending` | يقفل المستندات العالقة من نسخة الاعتمادات القديمة (لو موجودة) — `--dry` يوريك من غير تنفيذ |

نفس الزراير في **الإعدادات ← أدوات الداتا** (للأدمن بس).

**الفرق بين النسختين:**
`lv:demo` للفهم والتجربة — بيوريك السيستم وهو شغّال بكل مستنداته.
`lv:master` للشغل الحقيقي — بيجهّز الكتالوج بس وتمشي إنت الدورة من أول طلب شراء.

## نقاش المستندات

كل مستند فيه خيط نقاش زي التيكيت: استفسار من قسم لقسم، رد، قرار، وصور إثبات
(صورة قماش، عيب، الورقة الأصلية). المذكورين بيوصلهم إشعار، والتعليقات
ما بتتحذفش بعد ربع ساعة — دي سجل المستند.

## بعد كل إجراء

السيستم بيقولك تلات حاجات: **إيه اللي حصل**، **مين عليه الدور دلوقتي وهيعمل إيه**،
و**لينك مباشر للشاشة** اللي هيحصل فيها. الرقم الأحمر جنب الشاشات في المنيو
معناه فيه شغل عليك إنت هناك.
